## 2026-10-22: Performance

### Idle timers

- [x] Engagement's 15 s interval runs only while the tab is active, and the 5 s flush interval is armed on enqueue and cleared once the buffer is empty: `src/engagement.ts`, `src/transport.ts`.

### Cheaper `pagehide` save

- [x] `Outbox.save` splices into the stored array text instead of reading, parsing and rewriting it; `take` enforces the cap: `src/outbox.ts`.

### Chunked unload flush

- [x] The unload flush sends one beacon per chunk of at most `maxBatchSize` events and about 60 KB, and chunks the beacon refuses go to the outbox, so a 1000-event buffer is no longer dropped past the browser's 64 KB cap: `src/transport.ts`
